# APOD

Statische demo (HTML, CSS en afbeeldingen) van cross-document view transitions, zonder JavaScript. Elke navigatie krijgt dezelfde animatie. De versie met de Navigation API staat in `06-apod-navigation-api`. Er zijn geen dependencies.

## Starten

Open de map in VS Code en start de Live Server-extensie op `index.html`. Een andere statische server werkt ook, bijvoorbeeld:

```bash
python3 -m http.server 3000
```

Op Windows gebruik je `py -m http.server 3000`. Open daarna http://localhost:3000.
