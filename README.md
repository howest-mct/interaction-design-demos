# MCT Interaction Design Demos

Demos for the Interaction Design course, per chapter. Each folder is a standalone demo in plain HTML, CSS and JavaScript.

Open a demo in CodeSandbox:

```
https://codesandbox.io/s/github/howest-mct/interaction-design-demos/tree/main/<chapter>/<demo>
```

This repo is synced automatically. Don't edit it directly: changes are overwritten on the next sync.
